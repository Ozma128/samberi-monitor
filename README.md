# 🛒 Самбери: Система автоматического мониторинга ценников конкурентов

Современный программный комплекс на базе **Vision AI** (Google Gemini 1.5 Flash / GPT-4o-mini) для пакетной обработки фотографий ценников конкурентов, нечеткого сопоставления номенклатуры с базой сети «Самбери», расчета **Price Index (PI)** и экспорта в структурированный Excel.

---

## 📋 Структура итоговой таблицы
1. **Код нашего товара** (SKU Самбери)
2. **Наименование товара** (по номенклатуре Самбери)
3. **Распознано с ценника** (название и фасовка у конкурента)
4. **Цена закупки товара** (себестоимость)
5. **Цена продажи товара** (регулярная полка Самбери)
6. **Цена на промо у товара** (акция Самбери)
7. **Текущая цена конкурента** (регулярная цена на ценнике)
8. **Цена на промо у конкурента** (акционная цена / по карте лояльности)
9. **Разница цен (руб.)**
10. **Price Index (PI %)**
11. **Статус выгодности** (🟢 Самбери выгоднее / 🔴 Конкурент выгоднее / 🔵 Паритет)
12. **Предупреждения** (🟡 Демпинг: цена конкурента ниже закупки Самбери)

## 🚀 Быстрый запуск на вашем ПК

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск веб-приложения
```bash
streamlit run app.py
```
Приложение откроется в вашем браузере по адресу: `http://localhost:8501`.

## ⚡ Особенности и возможности
* **Параллельная обработка 100+ фото:** за 30–60 секунд благодаря многопоточному Vision AI API.
* **Встроенный демо-режим:** возможность протестировать всю систему без регистрации и без ввода API-ключей.
* **Нечеткий матчинг (RapidFuzz):** распознает сложные сокращения ритейла («мол. 3,2% пл/бут» $\rightarrow$ «Молоко ультрапаст. 3.2% ПЭТ»).
* **Аналитический дашборд:** графики соотношения цен, средний и корзинный Price Index, выявление аномалий и рисков демпинга.
* **Экспорт в Excel:** генерация профессионально оформленного отчета с цветовой заливкой строк, денежным форматированием и формулами.
* **Поддержка круглосуточной работы 24/7:** инструкции для развертывания на VPS-сервере за 200 руб/мес и мобильный Telegram-бот для торгового зала.
