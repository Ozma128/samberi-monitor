# Самбери — мониторинг ценников конкурентов

Приложение распознаёт фотографии розничных ценников через Google Gemini,
сопоставляет товары с каталогом Самбери, рассчитывает Price Index и формирует
проверяемый Excel-отчёт. Веб-интерфейс реализован на Streamlit; для мобильного
сбора фотографий доступен отдельный Telegram-бот.

## Что делает система

1. Принимает справочник Самбери в CSV или XLSX.
2. Проверяет и нормализует JPEG/PNG либо изображения из ZIP до отправки во
   внешний API.
3. Получает от Gemini структурированные сведения о товаре, цене, промо,
   фасовке и уверенности распознавания.
4. Сопоставляет ценник с каталогом с учётом бренда, массы, объёма, количества в
   упаковке и жирности. Несовместимые или неоднозначные варианты не
   сопоставляются автоматически.
5. Приводит цену за 100 г, килограмм или литр к фасовке найденного SKU,
   рассчитывает разницу цен и Price Index.
6. Показывает таблицу, сводные показатели и графики, затем выгружает книгу
   Excel из 12 стандартных колонок и отдельного листа «Сводка».

Price Index рассчитывается как `цена конкурента / цена Самбери × 100` по
эффективным ценам. Значение выше 102 означает, что Самбери дешевле; ниже 98 —
что дешевле конкурент; диапазон 98–102 считается паритетом. Условные
мультипромо не подменяют обычную цену безусловной скидкой.

## Быстрый локальный запуск

Рекомендуется Python 3.11 и отдельное виртуальное окружение.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Заполните в локальном `.env` как минимум:

```dotenv
GEMINI_API_KEY=<ключ Google AI Studio>
APP_PASSWORD=<длинный случайный пароль>
APP_AUTH_DISABLED=false
```

Случайный пароль можно создать локально, не передавая его сторонним сервисам:

```powershell
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

Запустите приложение:

```powershell
streamlit run app.py
```

По умолчанию оно доступно по адресу `http://localhost:8501`. Файл `.env`
игнорируется Git и предназначен только для локальной разработки. Не копируйте
его в образы, архивы, логи или систему контроля версий.

### Локальный режим без формы входа

Только на доверенном компьютере для разработки можно временно установить:

```dotenv
APP_AUTH_DISABLED=true
```

Не используйте этот режим на VPS, в общей сети, в Streamlit Community Cloud или
при публикации порта. В рабочем окружении оставьте `APP_AUTH_DISABLED=false` и
обязательно задайте `APP_PASSWORD`.

## Развёртывание в Streamlit Community Cloud

Облачный запуск использует тот же `app.py`; отдельный сервер и Docker не нужны.

1. Отправьте текущую версию в GitHub.
2. В Streamlit Community Cloud выберите репозиторий, ветку `main` и файл `app.py`.
3. В Advanced settings выберите Python 3.11.
4. В Secrets добавьте значения в формате TOML:

```toml
GEMINI_API_KEY = "<ключ Google AI Studio>"
GEMINI_MODEL = "gemini-3.6-flash"
APP_PASSWORD = "<длинный отдельный пароль>"
APP_AUTH_DISABLED = false
MATCH_THRESHOLD = 72
VISION_WORKERS = 2
MIN_RECOGNITION_CONFIDENCE = 0.55
```

Не загружайте `.env` и не коммитьте `.streamlit/secrets.toml`. Результаты и
предпросмотры хранятся только в текущей Streamlit-сессии: обновление страницы,
перезапуск или засыпание Community Cloud очищает их, поэтому готовый Excel нужно
скачивать после проверки партии.

## Конфигурация

Настройки читаются из переменных окружения; локальный `.env` подхватывается
автоматически. В Streamlit также можно использовать `.streamlit/secrets.toml`:

```toml
GEMINI_API_KEY = "<секрет>"
APP_PASSWORD = "<секрет>"
GEMINI_MODEL = "gemini-3.6-flash"
APP_AUTH_DISABLED = false
```

Переменные окружения имеют приоритет над Streamlit Secrets. Сам файл
`secrets.toml` не должен попадать в Git.

| Переменная | По умолчанию | Назначение |
|---|---:|---|
| `GEMINI_API_KEY` | нет | Обязательный ключ для реального OCR. Без него обработка не запускается. |
| `GEMINI_MODEL` | `gemini-3.6-flash` | Проверенная Vision-модель Gemini; имя должно начинаться с `gemini-`. |
| `APP_PASSWORD` | нет | Обязательный общий пароль веб-интерфейса, если аутентификация не отключена явно. |
| `APP_AUTH_DISABLED` | `false` | Отключает форму входа. Допустимо только локально при разработке. |
| `MATCH_THRESHOLD` | `72` | Порог автоматического матчинга, от 50 до 100. |
| `VISION_WORKERS` | `2` | Число параллельных запросов Gemini, от 1 до 4. |
| `MIN_RECOGNITION_CONFIDENCE` | `0.55` | Минимальная уверенность OCR для матчинга, от 0 до 1. |

Приложение работает по принципу fail closed: отсутствие `APP_PASSWORD` закрывает
веб-доступ, а отсутствие `GEMINI_API_KEY` блокирует OCR. Автоматического перехода
на правдоподобные тестовые данные нет.

## Формат справочника

Поддерживаются CSV в UTF-8/Windows-1251 и XLSX. Заголовки распознаются по русским
и английским алиасам, однако для предсказуемости используйте канонические имена:

| Колонка | Обязательность | Содержание |
|---|---|---|
| `код_товара` | обязательно | Уникальный SKU |
| `наименование_товара` | обязательно | Полное название, желательно с брендом и фасовкой |
| `цена_продажи` | обязательно | Положительная регулярная цена |
| `цена_закупки` | необязательно | Положительная закупочная цена для алерта демпинга |
| `цена_на_промо` | необязательно | Действующая промо-цена Самбери |

Дублирующиеся SKU, неоднозначные заголовки, отрицательные цены и строки без SKU
или названия отклоняются до запуска OCR.

## Лимиты загрузки

Проверки выполняются до передачи данных pandas, Pillow и Gemini:

- справочник — до 20 МБ, 100 000 строк, 100 колонок, 2 млн ячеек и
  64 МБ фактической памяти DataFrame;
- внутреннее содержимое XLSX — до 75 МБ и 10 000 объектов;
- входной ZIP — до 75 МБ, 500 объектов, 75 МБ распакованного содержимого и
  коэффициента сжатия 200:1;
- один JPEG/PNG — до 12 МБ и 25 млн пикселей;
- одна сторона изображения после нормализации — не более 4096 пикселей;
- одна веб-партия — до 50 входных файлов/изображений и 75 МБ суммарных
  исходных и нормализованных данных;
- одна сессия Telegram-бота — до 50 изображений и 75 МБ; неактивные сессии
  удаляются через 30 минут, бот принимает команды только в личных чатах;
- Telegram-бот ограничивает суммарную память активных сессий 256 МБ и запуск
  Gemini шестью партиями на пользователя за 15 минут, не чаще раза в 30 секунд.

Изображения декодируются, поворачиваются по EXIF и пересохраняются в JPEG без
исходных метаданных. Для ручной проверки в сессии хранятся только уменьшенные
предпросмотры суммарно до 10 МБ. Зашифрованные и подозрительно сжатые ZIP не
принимаются.

## Telegram-бот

Установите дополнительные зависимости и задайте явный allowlist пользователей:

```powershell
python -m pip install -r requirements-bot.txt
```

```dotenv
TELEGRAM_BOT_TOKEN=<токен BotFather>
TELEGRAM_ALLOWED_USER_IDS=<числовой user id>[,<ещё один id>]
SAMBERI_CATALOG_PATH=C:\secure-data\samberi_catalog.xlsx
```

После этого запустите:

```powershell
python deploy/telegram_bot.py
```

Бот не стартует без токена, ключа Gemini, существующего CSV/XLSX и непустого
allowlist. Не используйте username вместо числового Telegram user ID.

## Тестирование и локальные проверки

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest
python -m ruff check .
python -m pip_audit -r requirements.txt
python -m pip_audit -r requirements-bot.txt
```

Тесты не требуют реального API-ключа: интеграция Gemini подменяется контролируемыми
ответами. Они покрывают валидацию входных файлов, OCR-схему, матчинг фасовок,
аналитику, Excel-инъекции, оркестрацию и ограничения Telegram-бота. Эти же
проверки выполняются в CI.

## Структура проекта

```text
app.py                       Streamlit-интерфейс и защита входа
core/settings.py             единая конфигурация
core/input_validation.py     безопасная загрузка каталогов, ZIP и изображений
core/vision_extractor.py     Gemini Vision и валидация структурированного ответа
core/matcher.py              сопоставление с каталогом и контроль неоднозначности
core/analytics.py            нормализация цен, Price Index и сводные KPI
core/exporter.py             безопасный Excel-экспорт
core/pipeline.py             UI-независимая оркестрация обработки
core/rate_limit.py           общие in-process лимиты входа и запусков анализа
deploy/telegram_bot.py       Telegram-интерфейс с allowlist и лимитами
deploy/                      контейнеризация и руководство для VPS
tests/                       автоматические тесты безопасности и бизнес-логики
```
